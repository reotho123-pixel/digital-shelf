# 电子收纳（digital-shelf）

把自己所有物品和手机软件统计归类，并记录喜欢程度。手绘手账风格的 PWA，**数据只存在本机**，不联网、不上传。

## 现在能做什么

**总览** — 持有量、极简目标进度、快捷入口、分类卡片网格（衣物带季节分布）

**物品** — 卡片网格浏览，点分类卡跳转并自动筛选；卡片上直接改喜欢程度（爱心/圆环/破心）和状态（在用/收纳中/消耗中/待处理）；加/删照片；加/删物品（5 秒可撤销）

**物品详情** — 大图、数量步进器、放在哪、购入日期、备注；除名称外都能就地改

**软件** — 手机 App 清单，必需/暂用/待删三档，点标签直接归类；软件详情可改位置备注、换图标

**极简进程** — 目标对比（含超标溢出段）+ 每周趋势曲线（物品/款数/软件/分类四个维度）+ 里程碑；**快照每周自动记录**，不需要手动操作

**设置** — 分类管理（改名/删除/新增）、目标设置、**主色 5 种可切换**、照片风格、导出/导入备份（**可选合并或覆盖**）、清空数据

## 特色

- **手绘手账风格**：干笔刷涂笔主卡、手绘抖动描边、点阵纸、手写字体（站酷快乐体 + Kalam）
- **图片插画化**：上传的照片可自动转成插画感（纯前端 canvas 处理，照片不出设备），三档强度可调
- **离线可用**：Service Worker 缓存全部资源，装到手机主屏后断网也能用
- **数据持久化**：IndexedDB 存储，图片存 Blob；刷新、关掉重开数据都在

## 文件

| 文件 | 说明 |
|---|---|
| `app-prototype.html` | 应用本体（CSS/JS 全内联，零外部依赖） |
| `manifest.json` | PWA 清单 |
| `sw.js` | Service Worker，缓存名 `digital-shelf-v1` |
| `icons/` | 512 / 192 / 180 图标（手绘收纳盒） |
| `fonts/` | 自托管手写字体子集（约 800KB） |
| `PRD.md` | 需求文档（9 个页面规格、数据模型、边界规则） |
| `make-icons.ps1` | 图标生成脚本 |
| `_get-fonts.ps1` / `_get-fonts2.ps1` | 字体下载脚本（Google Fonts 子集） |

## 本地预览

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ..\serve-digital-shelf.ps1
# 打开 http://127.0.0.1:8767/app-prototype.html
```

## 改代码后

`sw.js` 顶部 `CACHE` 版本号 +1，否则已安装的用户拿不到更新。

## 数据

- IndexedDB 数据库名 `digital-shelf`，两个 store：`kv`（数据）+ `photos`（图片 Blob）
- 设置 → 导出备份（JSON，含图片）/ 导入备份
- **清空浏览器数据或删除 App 会丢失全部数据**，建议定期导出备份
